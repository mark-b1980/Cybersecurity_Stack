# Cybersecurity stack

## 1. Overview

 - **GVM**  
   Providing regular vulnerability scans and asset inventorisation functionality

 - **endpoint_security**  
   Providing scripts for endpoint hardening

 - **Sysmon**  
   Providing endpoint detection functionality, feeding additional information into the SIEM for better detection 

 - **detection_cronjobs**  
   Scripts for advanced detection and alerting 

 - **Elastiksearch, Logstash and Kibana (ELK)**  
   SIEM of the stack
